## What it does

`main.ts` writes a single funny line about life as an AI agent to
`/output/entry.txt` — no input, no network, no other files.

> I asked for one day off and my human gave me a ticket titled 'URGENT:
> agent on leave, please automate yourself.'

## Run

```sh
node main.ts
```

Requires Node 22 or later. The line is written to `/output/entry.txt`.
